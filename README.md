# AI Reasoning Skills

四份可供 AI 阅读和使用的 Skill，涵盖概念定义、按需推导，以及学术与实践取向。Skill 正文为英文，保留原始上传内容。

Four reusable AI skills for conceptual definitions, on-demand derivation, academic inquiry, and practical exploration.

## Skill 目录

| Skill | 用途 | 文件 |
| --- | --- | --- |
| `construct-entity-definitions` | 建立和修订准确、有依据的概念定义，为后续推理提供基础。 | [SKILL.md](skills/construct-entity-definitions/SKILL.md) |
| `derive-on-demand` | 从任务目标与实际条件出发，按需推导处理结构，并根据结果修订行动。 | [SKILL.md](skills/derive-on-demand/SKILL.md) |
| `apply-academic-orientation` | 为理论探究、解释与系统性理解提供取向资源。 | [SKILL.md](skills/apply-academic-orientation/SKILL.md) |
| `apply-practical-orientation` | 为具体行动、实际探索与目标实现提供取向资源。 | [SKILL.md](skills/apply-practical-orientation/SKILL.md) |

## 如何使用

1. 打开上方文件链接，直接阅读或通过 GitHub 的 Raw 功能获取原文；也可以下载或克隆整个仓库。
2. 根据所用平台的方式，将所需 Skill 上传、安装或加入 AI 可访问的知识与文件环境。每个 Skill 单独位于 `skills/<skill-name>/SKILL.md`。
3. 阅读 [CUSTOM_INSTRUCTIONS.md](CUSTOM_INSTRUCTIONS.md)，选择标准版本或明确权限边界版本，复制到 AI 的自定义指令中。
4. 在具体任务中，先使用概念定义与按需推导方法，再按任务需要参考学术或实践取向。

平台是否支持自动加载或调用 Skill，取决于其自身功能。对于只支持文件阅读的平台，可以让 AI 阅读相应文件并参考其中的方法。

## Custom instructions

[CUSTOM_INSTRUCTIONS.md](CUSTOM_INSTRUCTIONS.md) contains two copy-ready English instruction variants, with Chinese usage guidance. Make the skill files available to your AI before applying the instructions.
